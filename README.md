## 🎯 Objetivos de la Aplicación

**Juegos de Fonemas** es una herramienta pedagógica diseñada para apoyar a logopedas, maestros de Audición y Lenguaje (AL) y familias en el proceso de adquisición y corrección de fonemas. Sus objetivos principales son:

1.  **Conciencia Fonológica**: Desarrollar la capacidad de identificar y discriminar sonidos específicos en diferentes posiciones.
2.  **Precisión Articulatoria**: Proporcionar un modelo visual anatómico de alta fidelidad para que el niño comprenda el punto y modo de articulación.
3.  **Generalización**: Facilitar la integración de los fonemas corregidos en el lenguaje espontáneo a través de actividades lúdicas.
4.  **Motivación**: Convertir la terapia del habla en una experiencia gamificada y visualmente atractiva.

---

## 🕹️ Actividades y Metodología

La aplicación sigue una secuencia de aprendizaje estructurada a través de diferentes "mundos" o actividades:

### 1. 🧬 Simulador de Articulación (Inspirado en Sounds of Speech)
Herramienta técnica que muestra un corte sagital del aparato fonador.
- **Fases de movimiento**: Permite ver la lengua y mandíbula en reposo, articulación y liberación.
- **Apoyo Multimedia**: Enlaces directos a vídeos demostrativos y referencias académicas (UIowa).
- **Feedback Visual**: Representación del flujo de aire y vibración de cuerdas vocales.

### 2. 🚦 Semáforo de Pares Mínimos
Trabaja la **discriminación auditiva** comparando palabras que solo se diferencian en el fonema objetivo (ej. *Pera* vs *Pena*).

### 3. 📡 Radar de Fonemas
Un juego de búsqueda visual donde el niño debe identificar qué elementos contienen el sonido trabajado, fomentando la **atención y conciencia fonémica**.

### 4. 🚀 Pista de Despegue (Decir)
Enfocado en la **repetición dirigida**. Clasifica las palabras según la posición del fonema (inicial, medial, final o inversa).

### 5. 🎲 Juego de Mesa (El Gran Viaje)
Actividad de **generalización** donde se avanza por un tablero realizando pruebas de articulación con pictogramas de ARASAAC.

### 6. 🗣️ Frases y Trabalenguas
Entrenamiento de la **fluidez y precisión** en contextos lingüísticos más complejos y divertidos.

### 7. ✍️ Completar Frases
Integración **semántica y fonológica** donde el usuario debe identificar la palabra que falta basándose en el contexto de la oración.

## 🛠️ Cómo Funciona la App

1.  **Selección**: El profesional o el niño eligen el fonema o sinfón a trabajar (Z, S, R, RR, Sinfones con R).
2.  **Aprendizaje Visual**: Se inicia con el simulador para entender "dónde poner la lengua".
3.  **Ruta de Juego**: El niño navega de forma lineal por las actividades, recibiendo feedback visual (estrellas, cambios de color) al completar cada sección.
4.  **Acceso Rápido**: En cualquier momento se puede volver al simulador desde el menú principal para refrescar la posición articulatoria.

## 🚀 Instalación y Ejecución Local

Si deseas ejecutar este proyecto en tu propio entorno:

**Requisitos previos:** Node.js instalado.

1.  **Clonar e instalar dependencias:**
    ```bash
    npm install
    ```
2.  **Configurar API Key:**
    Configura tu `GEMINI_API_KEY` en el archivo `.env.local` (opcional, para funciones de IA).
3.  **Arrancar la aplicación:**
    ```bash
    npm run dev
    ```
